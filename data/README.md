# Data source and licence

`online_retail_2010_11.csv` is an unmodified row subset (all rows with
`InvoiceDate` in November 2010) of:

**Online Retail II**, UCI Machine Learning Repository,
https://archive.ics.uci.edu/dataset/502/online+retail+ii

Real transactions (2009-12-01 to 2011-12-09) of a UK-based, registered,
non-store online retailer. Licensed under **CC BY 4.0**.
